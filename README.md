# Deteccao_Fraudes_Bnacarias
Projeto de detecção de anomalias em transações financeiras utilizando Python e Machine Learning. Foram aplicados modelos de Regressão Logística, Random Forest e XGBoost, além de técnicas para lidar com o desbalanceamento dos dados, análise de métricas, ajuste de threshold e interpretação do modelo com SHAP.
